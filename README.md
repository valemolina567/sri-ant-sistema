# Sistema de Consulta Integrada

Proyecto desarrollado para la asignatura **ISWZ2202 - Diseño y Arquitectura de Software**.

## Descripción

Sistema web que permite consultar información tributaria, vehicular y puntos de licencia de un ciudadano mediante la integración con servicios externos del **SRI** y la **ANT**.

La solución utiliza una arquitectura basada en microservicios y aplica el patrón **Cache-Aside** para mejorar la disponibilidad y el rendimiento de las consultas realizadas al portal de la ANT.

## Tecnologías

- React (Frontend)
- Java (Backend)
- Redis / Cloud Cache
- APIs REST del SRI
- Portal Web ANT
- IcePanel (Modelado C4)

## Arquitectura

El proyecto fue diseñado utilizando el modelo **C4**, incluyendo:

- Diagrama de Contexto
- Diagrama de Contenedores

## Integraciones Externas

- Servicios Web del SRI
- Portal Web de la ANT
